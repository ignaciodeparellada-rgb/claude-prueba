# claude-prueba

Un proyecto de prueba para aprender sobre repositorios y Pull Requests en GitHub.

## Descripción

Este repositorio es un espacio para practicar y experimentar con Git y GitHub de forma segura.

## Instalación

```bash
git clone https://github.com/ignaciodeparellada-rgb/claude-prueba.git
cd claude-prueba
```

## Uso

Este es un proyecto de prueba. Puedes usarlo para aprender sobre:
- Crear ramas
- Hacer commits
- Abrir Pull Requests
- Colaborar en GitHub

## Contribuir

Las contribuciones son bienvenidas. Por favor:
1. Haz un fork del proyecto
2. Crea una rama para tu cambio (`git checkout -b feature/AmazingFeature`)
3. Commit tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request
